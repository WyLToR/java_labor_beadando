Film REST API

A REST API segítségével a film adatbázis rekordjai HTTP kérésekkel kérdezhetők le és módosíthatók.

Metódus Útvonal Funkció
GET /api/filmek Összes film lekérdezése
GET /api/filmek/{id} Egy film lekérdezése
POST /api/filmek Új film létrehozása
PUT /api/filmek/{id} Film módosítása
DELETE /api/filmek/{id} Film törlése

A válaszok JSON formátumúak, az API bejelentkezés nélkül használható.
