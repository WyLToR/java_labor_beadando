Az alkalmazásról

A MoziDB egy Java Spring Boot alapú szerveroldali webalkalmazás, amely MySQL adatbázisból jelenít meg film-, mozi- és előadásadatokat.

A rendszer autentikációt, szerepkör-alapú jogosultságkezelést, CRUD műveleteket, diagramot és REST API-t tartalmaz.
